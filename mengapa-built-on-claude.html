Mengapa newsroom kami built on Claude

Kami menguji tiga model untuk pekerjaan newsroom — dan memilih Claude karena satu alasan: paling patuh pada instruksi verifikasi berbahasa Indonesia.

1. Pekerjaan AI yang kami izinkan

  • Transkrip & ringkasan dokumen resmi (RDG BI, siaran ESDM, dokumen sidang). Output selalu menyertakan halaman/paragraf sumber.
  • Pra-skor draf dengan 9 sinyal Slop Score: clickbait ID/EN, AI-cliché (“delve”, “game-changer”, “merevolusi”), spam link/emoji.
  • Deteksi angka tanpa sumber. Setiap angka di draf wajib punya kutipan — kalau tidak, ditandai untuk reporter.

2. Yang tidak boleh dilakukan AI

  • Dilarang publish otomatis. Tidak ada artikel tayang tanpa dua pasang mata manusia.
  • Dilarang mengarang kutipan. Kutipan hanya dari transkrip terverifikasi.
  • Dilarang menghaluskan judul jadi clickbait. Judul = isi, skor judul harus ≤30.

3. Hasil setelah 3 bulan

  • Waktu cek draf turun dari ~40 menit ke ~12 menit per artikel.
  • 2 naskah clickbait per minggu rata-rata tertolak di tahap pra-skor.
  • Keluhan pembaca soal judul menyesatkan: nol dalam 30 hari terakhir.

4. Ke depan: SlopCheck API

Kami sedang memprototipekan SlopCheck API untuk publisher dan UMKM Indonesia — skor konten sebelum posting, dibangun di atas Claude API + filter ID-spesifik (slot, togel, money-bait). Program seperti Claude for Startups akan mempercepat ini: Claude Team untuk operasional newsroom + API credits untuk pengembangan API publik.

Prinsip kami: AI mempercepat verifikasi, manusia memutuskan kebenaran.
